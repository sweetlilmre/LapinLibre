# LapinLibre's core image: every entry of the root filesystem (rootfs:) and of
# /usr (usr:), its own boot included. One entry per line:
#   part:path f MODE UID:GID SOURCE        a file. SOURCE: target, the system build's target at the same
#                                          path (rootfs:P is target P, usr:P is target usr/P);
#                                          target:PATH, the target's file at PATH; own, our build;
#                                          core, image/core/<part>/<path> in this repository;
#                                          generated, made by image/tools/image.py (the sounds,
#                                          inetd.conf, the pinned firmware)
#   part:dir/* f MODE UID:GID generated    every file image/tools/image.py made in dir, each a file
#   part:path l TARGET                     a symbolic link
#   part:path d MODE UID:GID               a directory
#   part:path c|b MODE UID:GID RDEV        a device node
# "# ..." after an entry says why it is there, where that isn't obvious. Libraries are listed where
# they are; the build's library check adds any that are missing from the system build's target and fails
# on any listed that nothing uses.
