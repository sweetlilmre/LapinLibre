# Sound map

Every sound LapinLibre plays: its file, what it is, how it's made, and what plays it when. All the rabbit's own sounds are in `/usr/karotz/sounds`; the install's are on the key. All of them are LapinLibre's own. The tones are generated by the image build (`image/tools/image.py`); the spoken files are made once with Qwen3-TTS (`image/tools/speech_sounds.py`) or Kokoro (`image/tools/install_prompts.py`) and kept in the repo.

The web API's `sound_list` and `sound?id=NAME` take a sound's id as its file name without `.mp3` or `.wav`, looked up in `/mnt/usbkey/sounds` (the stick), then `/usr/karotz/sounds`; the first match wins.

## Effects (generated: `EFFECTS` in `image.py`)

| File | Played by | When |
|---|---|---|
| `acknowledge.mp3` | controller | New settings arrive from the app server; speech recognition matches an application's command, just before the application starts. |
| `wakeup.mp3` | controller, web API | Waking up: the scheduled wake-up, a triple click while asleep, the API's `wakeup`. |
| `error.mp3` | tag listener; the key's install | Before the phrase for a tag without an action or an unknown tag; the install stopped on an error (the same sound, `ERROR_SOUND` in `image.py`, also on the key). |

## Spoken (Qwen3-TTS: a native female voice per language, English cloned from Kokoro's British bf_emma)

The controller and the tag listener find these files through the language files (`/usr/karotz/res/lang/<language>`), so each language plays its own; a language without its own file plays en-US's.

| File | Language | When it plays |
|---|---|---|
| `en_tag_unknown.mp3` | English | The tag listener, after `error.mp3`: a tag that neither an application nor the web API knows is laid on the nose. |
| `fr_tag_unknown.mp3` | French | The same. |
| `de_tag_unknown.mp3` | German | The same. |
| `es_tag_unknown.mp3` | Spanish | The same. |
| `en_tag_no_action.mp3` | English | The tag listener, after `error.mp3`: a tag the web API knows but that has no action is laid on the nose. |
| `fr_tag_no_action.mp3` | French | The same. |
| `de_tag_no_action.mp3` | German | The same. |
| `es_tag_no_action.mp3` | Spanish | The same. |
| `en_speech_not_understood.mp3` | English | Speech recognition didn't understand what was said. |
| `fr_speech_not_understood.mp3` | French | The same. |
| `de_speech_not_understood.mp3` | German | The same. |
| `es_speech_not_understood.mp3` | Spanish | The same. |
| `speech_server_timeout_en-GB.mp3` | English | The speech recognition server didn't answer (every language but French). |
| `speech_server_timeout_fr-FR.mp3` | French | The same, when the rabbit speaks French. |

## Tones (generated: `SOUNDS` in `image.py`)

| File | Played by | When |
|---|---|---|
| `boot-ready.wav` | `startup.sh` | Once, at the end of boot, when the rabbit is ready. |
| `button-click.wav` | button watcher; web API | A single click on the head; tag learning stopped. |
| `button-double.wav` | button watcher | A double click. |
| `button-triple.wav` | button watcher; web API | A triple click; tag learning saw a tag it already knows. |
| `button-long.wav` | button watcher; web API | The start of a long press; tag learning started. |
| `notify.wav` | tag listener; controller; web API | A tag with an action, or an application's tag, is laid on the nose (the LED red), before the action or the application; a new tag is learned through the web API; the connection to the app server drops. |
| `shutter.wav` | webcam-daemon | Every snapshot. |

The button watcher plays its tones only while `/etc/conf/playsounds` exists (on from the first boot; the app server's settings can turn it off).

## The install (`sound/` on the key, played by the key's install with madplay)

| File | Made by | When |
|---|---|---|
| `key-found.mp3` | tone (`INSTALL_SOUNDS` in `image.py`) | The stick is seen, at the start of the install. |
| `checks-start.mp3` | Kokoro (`install_prompts.py`) | The checks begin. |
| `checks-passed.mp3` | Kokoro | The checks passed. |
| `checks-failed.mp3` | Kokoro | A check failed. |
| `install-start.mp3` | Kokoro | The install begins. |
| `install-busy.mp3` | tone | Over and over while the checks run and the flash is written. |
| `error.mp3` | tone (`ERROR_SOUND`, also in `/usr/karotz/sounds`) | The install stopped on an error; before `checks-failed.mp3` when a check failed. |
| `install-done.mp3` | Kokoro | The install is done, before the rabbit restarts. |

## Speech

What the rabbit says at run time (applications, the API's `tts`, the talking clock `apps/clock`) isn't a file: voice-daemon sends the text to the speech server `voice.conf` names for the language and plays the MP3 that comes back (`tools/app-server/tts_server.py` on the PC: Kokoro, with espeak-ng or Windows' speech for the languages Kokoro lacks).
