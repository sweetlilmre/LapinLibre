LapinLibre

Connecting to the rabbit…

Status

Telnet is on: anyone on your network can get a root shell on this rabbit without a password. Set TELNET=no in lapinlibre.txt and run the install to turn it off.

Sleep

Asleep, the rabbit takes no LED, ear, sound or speech requests; the camera still works.

LED

The rabbit's own software also sets the LED when its state changes (an application starting or ending, the app server coming or going), so the colour shown here is the last one set from this page or the API, which may no longer be what the nose shows.

Ears

One turn of an ear is 17 steps, counted from where recalibrating leaves it.

Sound

    Sounds come from the sounds folder of the USB key, then from the rabbit's own.

    Speech

    The rabbit speaks through the speech server of its app server (SERVER= in lapinlibre.txt, or TTS_SERVER= for a speech server of its own).

    Camera

    Every picture makes the rabbit's nose flash and plays the shutter sound, so it always shows the camera is in use. Pictures are kept in the rabbit's memory, the newest 10, until it restarts.

    Delete every stored picture?

      RFID tags

      Learning is off.

      While learning (2 minutes at most), lay each new tag on the rabbit's nose: it flashes green for a new tag and yellow for one it knows already. While learning is on, no tag runs its action, not even one that has an action. Outside learning, a tag with an action makes the nose flash and runs its action; the rabbit's own software may also say it doesn't recognise the tag.

        Tag

        The rabbit sends an HTTP GET to the URL, at most 15 s, and throws the answer away. A password is kept on the rabbit and never shown again. For https, the rabbit checks the server's certificate.

        This action has a password stored. Leave the password empty to keep it, or type a new one.
